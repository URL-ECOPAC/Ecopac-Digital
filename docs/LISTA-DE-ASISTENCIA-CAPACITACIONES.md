# Lista de asistencia a las capacitaciones - Ecopac Digital

Hojas para registrar quién asistió a cada sesión del plan de capacitaciones y si completó el ejercicio de comprobación, y cómo se guarda la evidencia de que la capacitación se impartió.

Se imprime una hoja por cada vez que se imparte una sesión. Si una sesión se repite con otro grupo, se usa una hoja nueva. Las hojas firmadas no llevan datos de pacientes.

| | |
| --- | --- |
| Versión | 1.0 |
| Fecha | 18 de octubre de 2026 |
| Acompaña a | Plan de capacitaciones, versión 1.2 |
| La llena | Quien imparte cada sesión |

---

## 1. Cómo se usa

1. **Antes de la sesión**, quien capacita imprime la hoja de esa sesión (sección 3) y anota fecha, lugar, hora y su nombre.
2. **Al empezar**, cada asistente escribe su nombre completo y su rol, y firma.
3. **Al terminar el ejercicio de comprobación**, quien capacita marca en la última columna "Sí" si la persona lo completó sola, o "No" si necesita repetir la sesión. Nadie pasa a la sesión siguiente con un "No" ([plan de capacitaciones](./manual/PLAN-DE-CAPACITACIONES.md), sección 5).
4. **El mismo día**, quien capacita:
   - escanea o fotografía la hoja firmada;
   - guarda el archivo, junto con la evidencia de la sección 2, en la carpeta **Capacitaciones** del Drive de la organización (`ecopac.digital@gmail.com`), con el nombre `AAAA-MM-DD-sesion-N`;
   - anota la sesión en el registro de la sección 10 del plan de capacitaciones: fecha, sesión, quién capacitó, cuántas personas asistieron y cuántas aprobaron.

Si una persona no completó la comprobación, se anota en "Observaciones" qué le faltó, para repasarlo con ella.

## 2. Evidencia de cada sesión

Además de la hoja firmada, por cada sesión se guarda en la misma carpeta:

| Evidencia | Cómo |
| --- | --- |
| Hoja de asistencia firmada | Escaneada o fotografiada completa, legible |
| Fotografía de la sesión | Una o dos, del grupo trabajando. **Sin pantallas que muestren datos**: aunque en la capacitación solo se usan datos de demostración, una foto de pantalla puede confundirse con datos reales |
| Ejercicios de comprobación | La lista de tareas de cada persona, con lo que logró marcado |
| Material usado | Qué manuales, guías y videos se usaron, si no fueron los que indica el plan |

Las fotografías solo se toman con el permiso de las personas que aparecen en ellas. Ninguna evidencia va al repositorio de código: el repositorio es público, y las hojas llevan nombres y firmas.

## 3. Hojas de asistencia

Una hoja por sesión. El contenido de cada sesión, su dinámica y su ejercicio de comprobación están en el plan de capacitaciones, sección 6.
